# DN1Sup Benchmark (dn1sup_benchmark)

Бенчмарк производительности SketchUp с акцентом на интерактив: 3D-вид (вьюпорт)
на сложных моделях, скорость редактирования, навигация по иерархии групп,
наложение текстур. Призван сравнивать разные версии SketchUp на одной машине.

## Что измеряет

| Группа | Тесты |
|---|---|
| Построение сцен | время генерации тестовых сцен (ядро геометрии) |
| Вьюпорт | FPS рендера (статичный вид и орбита), Zoom Extents |
| Иерархия | вход/выход из вложенных групп (`active_path=`), пошаговый спуск, обход дерева инстансов |
| Редактирование | push/pull батча граней, перемещение инстансов, правка определения (пересчёт инстансов) |
| Текстуры | загрузка PNG 256/1024/2048, батч-наложение текстуры, перекраска сцены, цветные материалы |

Тестовые сцены детерминированы (только формулы, без случайностей) — на любой
версии SketchUp геометрия идентична, метрики сравнимы.

## Запуск

- Меню **Extensions → DN1Sup → Benchmark**: «Прогнать бенчмарк (полный)…» или
  «Быстрый прогон (quick)…». Прогон идёт в фоне, UI не блокируется; по завершении
  открывается диалог с путём отчёта.
- Программно (мост/оркестратор): `Dn1supBenchmark.benchmark_steps(profile)` →
  пошагово `benchmark_perform(step)`; для FPS-шагов — пауза на время замера,
  затем `benchmark_fps_collect`.
- Сравнение прогонов: `Dn1supBenchmark.benchmark_compare([json1, json2, ...])`.

## Отчёты

Пишутся в `Documents/SketchUp Benchmarks/`: JSON (сырые данные) и
самодостаточный HTML (таблицы + SVG-диаграммы, без интернета). Сравнительный
отчёт показывает % к базовому прогону: зелёным — лучше, красным — хуже.

## Важно

- Вся работа идёт внутри undo-транзакции и откатывается: модель после прогона
  возвращается к исходному состоянию. Во время прогона сцены появляются и
  исчезают в вьюпорте — это часть теста.
- Для честного сравнения версий запускайте один и тот же профиль на одной
  машине без других тяжёлых приложений.

## Разработка

Dev-цикл — через MCP sketchup-dev: `ext_check` → `ext_install` → `ext_reload` →
`ext_test`. Тесты в `dn1sup_benchmark/test/` работают и в живом SketchUp
(`ext_test`), и локально (`ruby test/main_test.rb`, модельные уйдут в skip).
